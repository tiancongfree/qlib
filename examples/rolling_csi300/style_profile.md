## alpha 的基本原理 (理论)

### 1. alpha = 市场定价错误, 不是风险补偿

- 有效市场假说下无 alpha, 超额收益只是风险补偿 (Fama)。若 alpha 只是风险补偿, 应对某个风险因子有显著暴露
- **本策略证据**: 超额对大小盘 beta≈0.08 (R²=0.005)、对红利相关 0.001 → 对可观测风格因子几乎零暴露 → 是真 alpha 而非风险补偿
- 真 alpha 来源 = 行为偏差 (过度反应、处置效应、羊群、注意力有限) + 信息摩擦产生的**可预测定价偏离**

### 2. 定价错误存在的条件

- 行为偏差导致价格系统性偏离内在价值, 且偏离可预测
- A股 50%+ 散户交易占比 → 定价错误频繁且大 → A股 alpha 比美股厚
- 机构也是"别人的错误"的来源之一 (拥挤、追涨杀跌)

### 3. 定价错误 ≠ 免费捡钱

中间隔着: 错误的可预测性 (IC 波动说明纠偏节奏不稳)、信息摩擦 (谁能先看到)、交易成本、错误持续期 (价值股可长期低估)

### 4. 证据链 (本策略)

1. 对风格因子零暴露 → 不是 beta
2. IC 周期性波动 (错误出现→纠偏→再出现) → 符合行为周期
3. 2025 年超额暴跌 (+3%) → 错误变少/纠偏延迟, 市场阶段性更有效
4. A股厚度 > 美股 → 散户行为偏差更多

### 5. 反直觉推论

**错误越少 (市场越有效) alpha 越薄**。2025 超额 +3% 可能就是市场阶段性更有效。策略本质是**在捕捉他人行为错误上做轮动**, 错误模式变化时需重训适配新错误形态。因子会周期衰减而非永远有效。

## 回测→实盘差距评估 (100w 资金)

### 测试 (n_drop=1, 2020-01~2026-07, 100w)

| 场景 | 成交价 | 成本 | 年化超额 | IR | 期末净值 |
|---|---|---|---|---|---|
| A (当前回测, 净成本) | close | 0.2% | 17.1% | 1.29 | ~2.5 |

### 结论

1. **真实年化估计 ~17% (净成本)**
2. **成本影响可忽略**: 换手 16/yr × 0.2% ≈ 0.03%/年, 低频策略费率不敏感
3. **冲击成本几乎为零**: 100w 买 top30 = 3.3万/只, 持仓为 csi300 大盘股 (日成交 5-100亿), 冲击 3.3万/10亿 ≈ 0.003%
4. **其他摩擦影响小**: 涨跌停 (≤9.5% 已模拟, 连续涨停买不进占小比例)、停牌 (冻结资金)、打新 (实盘有增强, 回测没有, 实盘可能略好)
5. **核心结论: 100w 资金下回测≈实盘, 甚至实盘可能略好**。低频换手 + 大盘股 + 小资金 = 无冲击成本。机构吐槽"qlib 是玩具"主要针对百亿资金的冲击/容量/滑点场景, 对小资金研究策略 qlib 回测相当接近实盘
6. **保守估计**: 回测年化 17.1% → 实盘预期 **15-20%**, 打 10-15% 折让, 但远没有机构说的那么"玩具"

### 机构说"qlib 是玩具"的解读

- **合理之处**: 回测引擎简化 (close成交/固定成本/无冲击模型/无容量)、日频信号生态、生产化缺失 (无实盘风控/撮合仿真/订单管理)、纯 Python 性能
- **本策略实测价值**: rolling 框架/handler 抽象/特征缓存/实验管理 → 40分钟跑完 27 期滚动回测, 研究迭代速度机构也认可; dvratio 因子/PIT/日频提速都在框架内快速实现
- **判断**: qlib = 研究工具 (快速验证想法), 非生产系统 (执行层)。对单机个人研究者, 短板 (生产化) 不需要, 长板 (快速回测) 正是需要的
- **真正要警惕的不是"玩具与否", 而是别把回测结果当实盘预期**
